인수인계 A to Z 0.2.0 — 사진·업무표·사용설명서 검토 기록
확인일: 2026-10-20

완성한 흐름
- 하는 방법/진행 단계 옆 사진 넣기, 파일 선택·드롭·이미지 붙여넣기 이벤트, 미리보기와 설명, 확대, 삭제 확인.
- 사진 바이트까지 단일 JSON에 포함. v1 내용 유지, 사진 추가 시 v2. 사진은 서버나 AI로 전송하지 않음.
- IndexedDB 임시저장. 이전 localStorage 원본을 남겨 이관, 완료된 트랜잭션만 저장 성공으로 표시.
- 담당 역할 > 큰 업무 > 작은 업무 제목의 자동 업무표. 해당 업무로 이동하고 같은 제목으로 복귀.
- DOCX 사진·캡션, DOCX·인쇄 말미의 선택 범위 업무표.
- 사용방법: 인계자/인수자 3분 시작과 상세 주제 25개. 실제 공개 가상 화면 JPG 5개와 번호·설명·대체 텍스트.
- PDF 쪽번호만 읽힌 페이지 경고와 반복 머리말을 고려한 제목 후보. 원문은 그대로 보존.

용량과 호환성
입력 사진: JPEG/PNG/정지 WebP, 8 MiB·1,600만 픽셀·한 변 8,192픽셀.
저장 사진: PNG/JPEG, 한 장 2 MiB, 업무당 20장, 문서당 100장·합계 16 MiB.
JSON: v1 5 MiB, v2 24 MiB. 이전 0.1.x 앱은 v2 미지원.
기기 저장: 최대 30개 문서, 현재 목록 UTF-8 합계 64 MiB. 브라우저 실제 여유 용량은 별개.
전체 크기 PNG가 한도를 넘으면 축소 JPEG를 제시하고 사용자가 확인 후 선택. 원본 파일 미변경.

자동·문서 검사
npm test: 233개 통과 / 실패 0 / 생략 0.
npm run check, npm run build, git diff --check 통과. 새 의존 패키지 없음.
JSON 한글·긴 본문·사진·캡션 왕복, 새 사본 ID, 손상/과대/악성 입력 방어.
DOM 사진 추가·취소·삭제, 이벤트 붙여넣기/드롭, 수행 기록 분리, 검색, 확대·업무표 복귀.
저장 트랜잭션 모형: 이관 원본 보존, 충돌, quota/abort/timeout/versionchange, 실패 복구, 64 MiB 사전 제한.
실제 DOCX OOXML 재열기 및 LibreOffice PDF 렌더. 가로·세로 사진 3장과 캡션의 페이지 내 배치 확인.
긴 제목 30개 DOCX/PDF: 말미 업무표 10쪽에 전체 제목 보존, 표 머리글 반복 확인.
실제 제공 문서 2개는 비공개 폴더에서만 검증. 원본·내부 내용은 공개 파일과 캡처에 포함하지 않음.

실제 공개 Chrome에서 확인
HTTPS https://erakeun.github.io/handover-a-to-z/ 의 배포 코드 해시가 로컬 빌드와 일치.
새 검사 탭에서만 작업. 기존 6개 문서의 이름·업무/진행 건 개수를 관찰하고 새 가상 문서 1개 추가.
합성 가로 PNG 480x300와 세로 PNG 300x480 표시, 수정 캡션 저장 및 읽는 화면 반영.
사진 확대, Escape 닫기, 사진 버튼으로 키보드 초점 복귀.
업무표의 10개 제목 표시, 주간 회의 업무로 이동, 돌아오면 해당 제목으로 초점 복귀.
‘접수’ 검색 2건 및 요약 상세 펼치기. 수행 체크 완료 안내.
자동 저장 후 실제 새로고침: 문서명·가로 사진·수정 캡션·수행 체크 복원.
검사 탭을 닫고 새 탭으로 재접속: 같은 항목 복원, 세로 사진도 확인. 기존 6개 목록·항목 수 유지.
390x844 viewport: 문서 가로 폭 390, 사진 폭 288, 가로 넘침 없음. 사진 확대·Escape 닫기 확인 후 원래 크기로 복구.
assets/guide의 JPG 5개는 실제 공개 화면. 시작 화면은 기존 문서 목록을 제외해 촬영.
이 사진 표시 검증은 OS 파일 선택이나 사진 추가 경로의 검증을 뜻하지 않음.

검증하지 못한 것
실제 OS 파일 선택, 이미지 클립보드, 드롭, 다운로드 완료, 브라우저 인쇄창.
브라우저 프로세스/기기 강제 종료 후 복원, 실제 휴대전화, 스크린리더, Microsoft Word/Hancom DOCX 렌더.
사진 코덱/canvas 입력 정규화와 IndexedDB 오류의 자동 검사는 명시적 API/트랜잭션 모형 포함.
Chrome file URL 접근 및 localhost 우회 제한 유지. 권한 변경이나 거부된 파일 선택·다운로드 경로 재시도 없음.

제품 한계
DOCX/PPTX/HWPX/PDF의 사진 추출·업무 연결, PDF 표 구조 복원, HWP 직접 파싱, 스캔 OCR, 외부 AI 자동 해석 미지원.
사진은 설명 구역(method/steps)에 연결됨. 특정 단계 번호를 구조적으로 추적하지 않아 캡션으로 설명해야 함.
자동저장은 파일 백업을 대신하지 않음. JSON·DOCX는 암호화 파일이 아님.

공개 반영과 승인 이력
최초 push/PR 시도는 저장소·변경 묶음에 대한 승인이 명확하지 않아 자동 승인 검토가 실행 전에 거절함. 원격 변경 없음.
이후 사용자가 이번 코드·합성 예시의 push/PR/merge/Pages 배포를 명시 승인하여 알려진 미실행 작업을 1회 재시도했고 성공함.
